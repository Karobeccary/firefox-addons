# Firefox add-ons

Signed builds of my self-distributed Firefox / LibreWolf add-ons, plus the update list the browser checks.

| Add-on | What it does |
|---|---|
| Start Page | Customisable new tab and home page with shortcut groups, search, weather and news widgets |
| RES for Lemmy | Reddit Enhancement Suite-style tools for Lemmy |

**Install:** open the latest release for the add-on, download its `.xpi` in Firefox or LibreWolf, and confirm the install.
After that, the browser updates it automatically from [`updates.json`](updates.json).

Every file here is signed by Mozilla. Releases are published by a script, so please don't edit `updates.json` by hand.
